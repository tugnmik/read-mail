Tài Liệu Tích Hợp API

Sử dụng các endpoint dưới đây để tích hợp công cụ đọc mail (Microsoft Graph API) vào hệ thống của bạn.

POST /api/read-mail-stream Đọc số lượng lớn tài khoản (NDJSON Streaming)

Tối ưu cho việc đọc từ 50-100 accounts đồng thời. Trả về dữ liệu dạng luồng (stream), mỗi dòng là một JSON độc lập ngay khi có kết quả.

Request Body
"accounts": [
  {
    "email": "test@hotmail.com",
    "password": "pass", // Optional
    "refresh_token": "M.C524_BAY...",
    "client_id": "9e5f94bc-..."
  }
]
Response (application/x-ndjson)
// Dòng 1 stream về ngay lập tức khi account 1 xong
{"email": "test@hotmail.com", "status": "ok", "messages": [{"id": "...", "subject": "Verify code"...}]}
// Dòng 2...
{"email": "error@hotmail.com", "status": "error", "error": "Token het han"}
POST /api/mail-all Chỉ định số lượng thư cần đọc của 1 tài khoản

Lấy danh sách N thư mới nhất từ một tài khoản cụ thể.

Request Body
{
  "refresh_token": "M.C524_BAY...",
  "client_id": "9e5f94bc-...",
  "limit": 10 // Số thư tối đa (Mặc định: 10)
}
Response (application/json)
{
  "messages": [
    {
      "id": "AQQkADAwATM3AD...",
      "subject": "Welcome to Figma",
      "from_name": "Figma",
      "from_address": "support@figma.com",
      "date": "2026-03-17T13:51:00Z",
      "snippet": "You are now verified as a student..."
    }
  ]
}
POST /api/mail-detail Lấy nội dung HTML chi tiết của 1 thư

Sử dụng Message ID (được trả về ở các API trên) để lấy mã nguồn HTML nguyên bản của email để render / hiển thị.

Request Body
{
  "refresh_token": "M.C524_BAY...",
  "client_id": "9e5f94bc-...",
  "message_id": "AQQkADAwATM3AD..."
}
Response (application/json)
{
  "id": "AQQkADAwATM3AD...",
  "subject": "Welcome to Figma",
  "from_name": "Figma",
  "from_address": "support@figma.com",
  "date": "2026-03-17T13:51:00Z",
  "html_body": "<html><body>...</body></html>",
  "content_type": "html"
}
